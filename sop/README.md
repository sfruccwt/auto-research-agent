## 文件

| 本地文件 | 原文件 | 作用 |

| `workflow.md` | `research-capability/workflow/research-workflow-v0.2.md` | 研究主流程：定义问题 → 宽搜建图 → 拆主流观点 → 找反对意见 → 综合判断 → 转动作 |

## 使用说明

这是参考资料，不是固定不可改的指令。本工作区将基于它走 SpecKit 流程，改造成 Claude Code 上可用的 research runner。后续修订**直接改这里的文件**，OpenClaw 那边的原文档不再回写。
