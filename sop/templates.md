# research-capability：最小模板包 v0.7

定位：在 `v0.6` 基础上，只做一轮真正服务“能干活”的最小补位。  
本版重点：不扩模板数量，不拉新框架；只把“待比较路径 / 当前主路径 / 建议分流”这三处补进模板，减少研究结果停在记录层的概率。

## 本版模板包设计意图（v0.7）

- 模板 1 继续负责：把主题压成决策问题，并显式列出待比较路径
- 模板 2 继续负责：把第一轮地图压成当前判断、当前主路径、最短证据链与待证点
- 模板 3 继续负责：把最终结果压到路径分流、动作上限、下一步、观察信号与推翻条件
- 本版只做小补位，不扩模板数量，不引入新框架

---

## 和 v0.6 相比的最小变更

1. 在模板 1 补入 `当前待比较路径 / 候选动作`
2. 在模板 2 的第一轮地图补入 `现实摩擦 / 动作条件`
3. 在模板 2 的当前判断补入 `当前最值得继续看的路径`
4. 在模板 2 的竞争判断补入 `最可能改变路径排序的信息`
5. 在模板 3 把 `可选路径` 收口为 `路径分流（推进 / 继续比较 / 暂缓 / 放弃）`
